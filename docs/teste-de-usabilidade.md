# Roteiro de teste — jogador que nunca leu o guia

Proposto pela professora no feedback da demo: verificar se uma pessoa que **não leu o
README nem o "Como jogar"** consegue entender o jogo só pelo primeiro turno.

## Preparação

- Partida nova com o tutorial **ligado** (menu → "TUTORIAL NO 1º TURNO: LIGADO").
- Participante sem contato prévio com o projeto, o GDD ou este repositório.
- Um observador por sessão, com este roteiro. Não explique nada durante o jogo;
  se a pessoa perguntar, responda "o que você acha?" e anote a dúvida.
- Duração: 10 minutos de jogo + 5 minutos de perguntas.

## Durante o jogo (observar e anotar)

| Momento | O que observar | Anotação |
|---|---|---|
| Despertar | Leu o visor inteiro? Clicou em "INICIAR SISTEMAS" ou pulou? | |
| LiDAR | Encontrou o botão destacado sem ajuda? Em quanto tempo? | |
| Primeiro passo | Clicou no hexágono destacado? Olhou o custo antes de confirmar? | |
| Primeiro evento | Leu os custos dos botões antes de escolher? | |
| Bateria baixa | Percebeu o alarme e a barra piscando? Mudou de plano? | |
| Núcleo | Entendeu que o passo ficou mais caro depois de carregar o núcleo? | |

## Depois do jogo: as três perguntas

Faça as perguntas abertas, sem sugerir respostas, e anote as palavras da pessoa.

1. **Quem é N-7?**
   Esperado: um robô/autômato que carrega a Lógica (o conhecimento humano) num domo em colapso.
2. **O que você precisa fazer?**
   Esperado: achar os núcleos da Natureza e da Arte e levar os três ao Elevador Central.
3. **Quanto vai gastar para dar o próximo passo?** (pause o jogo numa situação qualquer)
   Esperado: um número em % de bateria, lido na prévia da rota ou calculado pela fórmula da HUD.

A demo passa se **pelo menos 4 de 5** participantes acertarem as três perguntas. Cada
resposta errada vira uma issue com o rótulo `funcionalidade`, citando a anotação do
observador.
